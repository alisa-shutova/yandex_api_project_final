# Тест на проверку создания заказа и получения заказа по треку заказа с помощью API Яндекс Самокат.
Тест проверяет, что после создания заказа его данные можно получить по номеру трека.
- Для запуска тестов должны быть установлены пакеты pytest и requests
- Запуск всех тестов выполняется командой pytest
